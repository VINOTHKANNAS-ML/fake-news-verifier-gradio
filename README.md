# 🛡️ Agentic AI Fake News Verifier (Gradio Space)

A multi-agent AI pipeline that verifies **text, article URLs, images, and
audio** and returns an explainable trust score (0–100) with a verdict,
factor breakdown, sources, and recommendations — plus a downloadable PDF
report.

This is a Gradio port of a larger FastAPI + React project: same agents,
same scoring algorithm, repackaged as a single-file Space with no
database or login, so it deploys straight to Hugging Face.

**Works with zero API keys** — ships with `ENABLE_MOCK_MODE=true` by
default, using realistic simulated responses for every external service.

---

## 🚀 Deploying this Space

1. Create a new Space on Hugging Face → SDK: **Gradio**.
2. Upload every file in this folder, preserving the `app/` subfolder structure:
   ```
   gradio_app.py
   requirements.txt
   .env
   app/
   ├── config.py
   ├── agents/...
   ├── services/...
   └── utils/...
   ```
3. That's it — the Space will build and launch `gradio_app.py` automatically
   (set via `app_file` in this README's YAML header).

### Using real data instead of mock mode

By default the bundled `.env` sets `ENABLE_MOCK_MODE=true` (it contains no
real secrets — safe to commit). To use live APIs instead, go to your
Space's **Settings → Variables and secrets** and add:

| Name | Value |
|---|---|
| `ENABLE_MOCK_MODE` | `false` |
| `SERPAPI_KEY` | your key from https://serpapi.com |
| `GROQ_API_KEY` | your key from https://console.groq.com/keys (starts with `gsk_`) |
| `NEWSAPI_KEY` | your key from https://newsapi.org |
| `HUGGINGFACE_API_KEY` | your token from https://huggingface.co/settings/tokens |
| `ASSEMBLYAI_API_KEY` | your key from https://www.assemblyai.com |

Secrets set in the Space always override the values in `.env`, so it's
safe to leave `.env` as-is.

DuckDuckGo and Wikipedia search need no key and are used either way.

## 🧠 How it works

Four tabs (Text / URL / Image / Audio) all feed the same pipeline:

```
Ingestion Agent → (Image/Audio Agent, in parallel) → Search Agent
      → Trust Scoring Agent → Explanation Agent → Result
```

- **Ingestion** extracts clean text (direct for text input, article
  scraping for URLs via BeautifulSoup, image captioning via HuggingFace
  BLIP, audio transcription via AssemblyAI).
- **Search** pulls corroborating evidence from SerpApi's fact-check
  search, NewsAPI, DuckDuckGo, and Wikipedia.
- **Trust Scoring** combines everything into a weighted 0–100 score:
  Source Evidence (40%), Content Consistency (25%), Media Authenticity
  (20%), Fact-Check Alignment (15%).
- **Explanation** turns the score into plain-language factors and
  actionable recommendations, plus a short Groq-generated "AI Analysis"
  narrative explaining the verdict in natural language.

Every run's full agent-by-agent log is visible in the "Agent Execution
Logs" accordion at the bottom of the results.
